Farmacia — Proyecto académico
Proyecto académico de desarrollo web relacionado con la gestión de una farmacia.

El repositorio conserva parte del trabajo realizado originalmente, incluyendo archivos correspondientes al panel principal (Dashboard), inicio de sesión (Login) y registro de usuarios (Register).

Estado del proyecto: Incompleto. Debido a la pérdida de gran parte del código original, actualmente solo se conserva una parte del desarrollo que fue posible recuperar.

Este repositorio se mantiene como evidencia del trabajo académico realizado y de la práctica adquirida durante el proceso de desarrollo.
